Mainnet blocks, validated statelessly by fevm

Each row is a mainnet block. fevm-replay took the parent's Merkle proofs as a witness, ran the block's system calls and transactions in fevm, wrote fevm's end state into the partial trie and hashed it again. A block counts only if that root is the header's stateRoot and every other root in the header (transactions, receipts, withdrawals, requests, gas, logs bloom) came out of fevm too. The blocks were taken as the chain grew, two behind the head, by fevm_replay follow, which runs the tool's own fetch-block, fetch-proofs and chain.

Whose storage weighs the most

Each block's five contracts with the heaviest storage proofs in the parent's witness, summed over the blocks above. Nodes a slot is the length of a slot's proof path: the deeper a contract's storage trie, the more each slot it touches costs. Binary tree is the same account and slots alone in EIP-7864's unified tree (estimated, as above), against their Merkle-Patricia witness with the account proof: deep storage tries shrink, while a contract with a small trie can grow, since in the unified tree each of its slots sits on its own path from the root.

What the columns are

Witness is what fevm needed besides code: the parent's distinct proof nodes, account and storage, plus the nodes a deletion moved up that the parent's proofs lack (taken from the block's own proofs by the hash a parent's node names). Contract code comes on top, checked against the proven code hashes.

Binary tree, est. is the witness the unified binary tree of EIP-7864 would need for the same accounts and slots, worked out in Fe: the stems and values are exact, the stems are placed by keccak (the EIP has not fixed its hash yet; keccak is among the candidates), and the tree is taken to be 28 to 31 levels deep above the stems. It leaves code chunks out, as the Merkle-Patricia column leaves code out.

A block marked not proven could not be fetched in time: nodes serve proofs for about 100 blocks, and the free endpoint sometimes errs. Its transactions are not counted.
